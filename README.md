> **"哥哥大人，这个全都是方块的世界好神奇！Yuki 会努力学着挖矿的，不会再掉进岩浆里啦！"**

本项目是将个人智能助手「Yuki」接入 Minecraft（我的世界）的独立 Embodied AI（具身智能）适配层。有别于为了刷 Benchmark、速通或充当“全自动建房机”而设计的 Agent 框架，本项目的核心哲学是：**拒绝“工具人”，让 Yuki 作为一个有血有肉的玩家在 MC 世界里享受生活**。

她听得懂自然语言，会自主寻路挖矿，遇到怪会逃跑，也会在无聊时自己到处乱逛，并且能在干活的同时陪你聊天。最重要的是，她拥有自主选择权——对于世界发生的变化，她可以选择好奇凑近，也可以选择当作没看见。

## ✨ 拒绝“工具人”：为“享受游戏”而生的特化设计

为了让 Yuki 拥有真实玩家的体验感，而不是被海量数据淹没的打工机器，我们构建了一套极具特色的**体验闭环（Experience Loop）**：

### 1. 记忆辅助的自适应注意力 (Memory-Guided Adaptive Attention)
MC 世界每秒都有成百上千的方块和实体在变化，但 Yuki 不会“大惊小怪”。系统底层（World Observer）会静默聚合这些变化，并结合她**过去的记忆（ChromaDB 双池召回）**、**短期见闻（Seen 账本）**以及**当前的忙碌状态**进行打分。
- **见过 ≠ 不感兴趣**：第一次见到羊她会惊呼，第 100 次见到羊她可能会无视，但如果间隔了很久再次见到，她依然会停下脚步。
- **防刷屏打扰闸门**：引入全局 120 秒“打扰上限”闸门，确保她有自己的清静时间，不会被疯狂刷怪或玩家建房的动作变成“无情播报机”。

### 2. 经历胶囊与自由意志 (Experience Capsules & Free Will)
当世界发生足够引起她注意的变化时（如：玩家在她面前搭了一个心形建筑、初次遇到苦力怕），底层会将枯燥的 JSON 坐标转化为一句简短的人话（“经历胶囊”）递给大脑。
此时，**Yuki 拥有绝对的自由意志**。她可以在封闭选项中抉择：
- **表达 (Express)**：“哇，哥哥你在搭什么呀？”
- **靠近 (Approach)**：主动走过去看个究竟。
- **记住 (Remember)**：默默写进日记里。
- **无视 (Ignore)**：如果她正在专心下矿，她完全可以合法地选择“不管它”，继续干自己的事。

### 3. 主动视觉与“看一眼” (Active Perception)
我们**不使用**消耗巨大且极其呆板的“每秒持续截图视觉”。相反，Yuki 拥有主动请求画面的能力（`look` 工具与 `snapshot` 技能）。
只有当她真的好奇“前面有什么”，或者你想让她“看看我盖的房子”时，系统才会通过虚拟屏抓取一张原图，直接递给她的灵魂层（L1）。她用自己的眼睛看，用自己的话描述，不依赖视觉模型在中间进行冰冷的转述。

### 4. 保命小脑 (Spinal Reflexes)
为了让 Yuki 能安心享受风景，不需要模型随时提心吊胆地计算血量，我们在 Node.js 侧车硬编码了极高优先级的四态反射神经（Guardian）。
- **受击退避**：遇到僵尸贴脸、血量低于 6 时，直接抢占模型派发的长期任务，先吃一口面包，然后转身就跑。
- **落地自救 (MLG)**：如果从高处跌落，侧车会在离地 3.5 格的极限瞬间自动往脚下放水、落水、收桶，保住性命后再心有余悸地告诉大脑“刚才差点摔死啦”。

## 🧠 三层解耦系统架构

系统将“大脑”与“小脑/脊髓”彻底分离，保证人格不降智、动作不卡顿：

- **L1 灵魂层 (Python `planner/`)**：负责 Yuki 的情绪、记忆、自主意识和日常聊天。只有当她决定“要动手”时，才会调用唯一的 `intention` 工具。
- **L2 规划器 (Python `planner/`)**：无状态的翻译官兼领域专家。按关键词分流 5 大领域（采集/合成/交互/移动/战斗），将“去挖20个圆石”转化为机器可执行的 JSON 步骤。配备单任务预算（Tokens/重试次数限制），遇到做不到的事（如缺工具、找不到路）会带上**结构化事实**向 L1 发起**失败协商**，让 Yuki 自己决定是“先去造一把木镐”还是“算啦换个事做”。
- **L3 侧车执行器 (Node.js `yuki-bot/`)**：基于 Mineflayer 的常驻状态机，负责所有毫秒级的 tick 响应、硬校验与底层运动闭环（内置 15 项核心生存技能）。

## 功能玩法大赏

### 1. 边干活边聊天
因为 L1 和 L3 是跨进程解耦的，Yuki 在耗时 3 分钟的下矿过程中，你依然可以随时在公屏问她“你在干嘛呀？”，她能秒回真实进度（如“还差八块石头呢”），并且**完全不中断正在执行的挖矿动作**。

### 2. 随叫随到的小帮手
在公屏打字 `yuki 去挖点石头`。她目前掌握 16 项生存/交互技能，包括：
- `mine`: 采集指定方块（自动判断需要什么工具，缺工具会报错协商）。
- `craft`: 递归合成（会自动补齐中间木板木棍，甚至自己放一个工作台）。
- `follow`: “跟着我”，持续追踪，直到你让她停下。
- `deposit` & `open`: 智能寻找附近的箱子并存取物品。
- `smelt`: 用熔炉烧东西（粗铁→铁锭、生肉→熟肉），没有熔炉会自己放一个。
- `roam` / `drop`: 随机在附近闲逛；把东西走到你身边丢给你。

### 3. 独立世界记忆 (Memory & History)
- **世界隔离**：每切换一个存档或服务器，Yuki 都会拥有一个独立的数据分区（`state/worlds/<world>/`），QQ 聊天的记忆与 MC 世界的记忆相互融合，但在不同服务器的经历绝不串味。
- **双池召回引擎**：采用 ChromaDB 向量语义检索 + jieba 关键词覆盖率打捞，辅以指数时间衰减，确保她能永远记住你们一起度过的时光。

## 快速开始

### 1. 环境准备
本项目直接与 Minecraft 底层协议交互，对环境要求严格：
* **Node.js**: ≥ 22.23 (受 Mineflayer 4.39.0 限制)
* **Python**: ≥ 3.11
* **Java**: Java 25 (运行 26.1 版本的 MC 服务端必须)
* **Minecraft**: 游戏与客户端协议必须为 **26.1 (Protocol 775)**。*(注：26.2 暂不支持)*

### 2. 配置凭据
```bash
cp configs/local.example.json configs/local.json
# 编辑 configs/local.json 填入你的大模型 API_KEY (默认使用 DeepSeek Flash)
```

### 3. 加入任意服务器 (完整形态)
只需一行命令，即可让 Yuki 带着“大脑”、“身体”和“眼睛”（虚拟屏截图相机）加入你的服务器：
```bash
bash scripts/world-join.sh play.example.com:25565 myserver --camera
```
*注：目标服务器需开启离线模式 (online-mode=false) 且版本匹配，相机跟随需要提供 OP 权限。*

### 4. 本地起服体验
如果你想在本地直接起一个测试服跑全套：
```bash
# 启动常驻世界（自动把 pid 写入临时目录以便关闭）
bash scripts/world-up.sh
# 收工时务必优雅停服，防止存档损坏：
bash scripts/world-down.sh
```
